## Research Design Overview — *From Signal to Meaning*

### Research Vision  
This project explores how human emotions can be **decoded, structured, and expressed** through physiological signals.  
It transforms affective computing from mere “recognition” into a **language-building process** — enabling machines not just to detect emotion, but to *speak it back* through **data, words, and sound**.  

The long-term goal is to bridge **neuroscience, computation, and art** — a world where emotional states become data, and data becomes resonance.

---

## Methodological Framework  

| Stage | Focus | Output | Innovation Layer |
|--------|--------|--------|------------------|
| **1️. Exploration (WESAD Terrain Mapping)** | Understand raw physiological data: ECG, EDA, RESP, labels | Data intuition, signal visualization, initial notes (S2) | Cognitive & analytical insight — grasping the “topography” of emotion signals |
| **2️. Formalization (Multi-Subject Timeline Construction)** | Turn implicit label segments into explicit, structured data tables | `subject_timeline.csv`, `subject_summary.csv` | Data-engineering innovation — making time and emotion explicitly linkable |
| **3️. HRV Feature Layer (Emotion Physiology Encoding)** | Extract HRV-based emotional indicators (RMSSD, SDNN, LF/HF, etc.) | `features_hrv.csv` | Physiological modeling innovation — quantifying how emotions shape the body |
| **4️. Lexicon Layer (Emotion Language Dictionary)** | Map physiological and contextual features to symbolic “emotion tokens” | `emotion_lexicon.json` / `lexicon_matrix.csv` | Conceptual innovation — defining an emotional grammar inspired by linguistics |
| **5️. Semantic Layer (Emotion Grammar & Interpretation)** | Build models that translate emotion tokens into structured meanings or multimodal outputs (text, color, sound) | Prototype model + visualization (Echo semantic demo) | Integrative innovation — from signal to semantics |
| **6️. Musical Layer (Emotion-to-Music Translation)** | Convert emotion lexicon and timeline into musical composition parameters (tempo, key, rhythm, harmony) | Generated MIDI / audio tracks | Artistic-scientific innovation — turning emotion data into soundscapes |
| **7️. Reflective Layer (Humanistic Integration)** | Examine ethical, psychological, and cultural implications | Essay *“The Human State Beyond Language”* + TEDx talk *“Ignition of Echo”* | Humanistic innovation — uniting science and creation |

## The Emotional Lexicon 

The **Emotional Lexicon** is a self-created dictionary that translates quantitative physiological states into symbolic, interpretable emotional units — *“emotion tokens.”*  

Each token encodes:  

| Dimension | Example | Source |
|------------|----------|--------|
| **Physiological** | HRV ratio, skin conductance | From HRV feature extraction |
| **Affective** | calm, tense, amused, fatigued | From WESAD labels + clustering |
| **Semantic** | `⟦E_Calm_01⟧`, `⟦E_Stress_07⟧` | Generated symbols for modeling |
| **Linguistic / Expressive** | mapped to words, tones, or visuals | Linked to lexicon grammar rules |
| **Musical Mapping** | key = C major, tempo = 120 bpm, intensity = mezzo forte | Derived from emotion-to-sound translation module |

This lexicon serves as both a **linguistic** and **musical vocabulary** of emotion —  
bridging affective states and expressive outputs.  
Each token can drive a *sentence, sound, or motif*, allowing physiological signals to be rendered as living language and music.

## The Musical Layer (Emotion-to-Music Translation)

This layer transforms the **emotional timeline and lexicon** into **musical compositions**.  
Using mappings between physiological features and musical dimensions, Echo creates sound that mirrors emotional dynamics.

| Emotion Dimension | Musical Mapping | Example |
|--------------------|------------------|----------|
| **Arousal / HRV variance** | Tempo | Higher arousal → faster tempo |
| **Valence / Emotional polarity** | Key signature | Positive → major; negative → minor |
| **Amplitude / Signal intensity** | Dynamics | Strong signal → louder dynamics |
| **Transition speed** | Rhythm complexity | Sudden change → syncopated rhythm |

The result is a **data-driven composition system** —  
where each subject’s emotional journey can be *heard* as a symphony of heartbeats and feelings.  

Outputs include:
- `emotion_music_map.yaml` — mapping rules between physiological features and musical parameters  
- `generate_music.py` — Python script generating MIDI via libraries such as `music21` or `mido`  
- `emotion_tracks/` — folder containing generated `.mid` or `.wav` compositions  
- `emotion_music_demo.ipynb` — notebook visualizing HRV-to-music transformation
